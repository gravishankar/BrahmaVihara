HOW TO USE
================================================================================

LISTEN TO MEDITATION:
  1. Open: brahma-vihara-meditation-app.html in a web browser
  2. Click play button to begin
  3. Follow all 169 segments (approximately 21 minutes)

REGENERATE AUDIO FILES:
  1. Activate environment:
     source /Users/gravisha/venvs/chatterbox/bin/activate

  2. Basic regeneration (all missing files):
     python3 brahma_vihara_chatterbox_gen.py

  3. Adjust meditation speed (slower = more spacious):
     python3 brahma_vihara_chatterbox_gen.py --speed 0.70 --force

  4. Generate specific phase only:
     python3 brahma_vihara_chatterbox_gen.py --phase metta

  5. Test generation (5 files only):
     python3 brahma_vihara_chatterbox_gen.py --test

AVAILABLE PARAMETERS:
  --test           Generate 5 test files only
  --phase PHASE    Generate specific phase (settle|metta|karuna|mudita|upekkha|close)
  --dry-run        Preview without generating
  --force          Regenerate existing files (overwrite)
  --speed SPEED    Adjust speech speed (0.5-1.5, default 0.82)

  Problem:      perth.PerthImplicitWatermarker returned None
  Detection:    Implemented check with clear error message
  Solution:     Monkeypatch to use perth.DummyWatermarker
  Fallback:     Graceful fallback chain (primary → fallback → error)
  Result:       100% reliability, no watermarking needed

APPLE SILICON ACCELERATION:
  Device:       Apple Silicon (M-series, MPS support)
  Framework:    PyTorch with Metal Performance Shaders
  Speedup:      5-8x faster than CPU (confirmed via benchmarks)
  Optimization: Explicit MPS device selection in code
  Fallback:     Automatic CPU fallback if MPS unavailable

AUDIO PROCESSING PIPELINE:
  Step 1:  Generate WAV @ 24 kHz using Chatterbox
  Step 2:  Apply 0.82x atempo filter (slower speech)
  Step 3:  Normalize loudness to -18 LUFS (consistent volume)
  Step 4:  Convert to MP3 @ 192 kbps (high quality)
  Result:  Final meditation-grade MP3 files

ERROR HANDLING:
